# XmlToJson

Ejercicio práctico desarrollado en Java durante mi formación en Desarrollo de Aplicaciones Multiplataforma (DAM).

## Descripción

Este proyecto consiste en realizar una conversión de datos XML a JSON utilizando Java y la biblioteca Jackson.

La aplicación trabaja con un archivo XML de entrada (`yo.xml`) y utiliza las dependencias necesarias para procesar los datos.

## Tecnologías utilizadas

- Java
- Maven
- Jackson
- XML
- JSON
- JUnit

## Estructura del proyecto

- `App.java`: clase principal de la aplicación.
- `XmlToJson.java`: clase encargada del proceso de conversión.
- `yo.xml`: archivo XML utilizado como entrada.
- `pom.xml`: archivo de configuración de Maven y sus dependencias.

## Objetivo

Practicar el procesamiento de archivos XML y JSON, así como el uso de bibliotecas externas en proyectos Java.
